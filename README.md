# WCT Stream Metabolism

Analysis code and input data for the WCT (Westslope Cutthroat Trout) stream
metabolism / production project.

## Structure

```
code/    R analysis scripts (run in order)
  01_Abundance.R       Depletion-based abundance estimates
  02_Growth.R          Growth model
  03_Bioenergetics.R   Bioenergetics simulations
  04_Production.R      Production estimates (combines outputs above)

Data/    Input data
  CTT.Data.2025.F.csv  Capture/tag/recapture field data
  temp.csv             Stream temperature series
  Stream.Metrics.xlsx  Stream metric summaries
  Cat/                 Raw dissolved-oxygen catalog files (per site, .TXT)
```

## Notes

Scripts reference data via relative paths (e.g. `Data/CTT.Data.2025.F.csv`),
so run them with the repository root as the working directory. Intermediate
`.RDS` result files are generated by the scripts and are not tracked here.
